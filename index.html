Request access to the private repository.

This public repository hosts project information only. The application source remains in the private CapitalCompass repository. Access is reviewed by its owner.

  1. Sign in to GitHub with the account you want to use.
  2. Submit an access request using the form below. Choose your intended use and add optional, non-sensitive context.
  3. Wait for review. If approved, the owner sends a GitHub repository invitation. Accept it to gain access.
Open access-request form Already invited? Open CapitalCompass

Public request, not a private support channel. Your GitHub username, request and comments are visible to others. Do not include passwords, API keys, account numbers, holdings, tax documents, email addresses or other private personal information. The form does not grant access automatically.

Before you request access

Why does the private link show 404?

GitHub normally hides private repositories from people without access. Submit a request here rather than expecting a permission page at that link.

Is this a hosted investment service?

No. This is a project landing page. Approved access provides repository access, not a hosted account, broker subscription or financial-adviser relationship.

Can the app place trades?

No. The current application is read-only. Research suggestions are not orders, suitability determinations or guarantees of returns.

Does access include market-data rights?

No. Model licenses, broker permissions, search terms and market-data rights remain separate. Review the project's financial-risk and privacy notices before using the app.

CapitalCompass is for investment research, not a substitute for qualified financial, legal or tax advice. AI and market data can be wrong or outdated. Investing involves risk of loss. Verify information independently.
